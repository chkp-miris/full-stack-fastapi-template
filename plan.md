**Models:** `AnalyticsEvent`, `SystemMetric`, `ApiUsageMetric`, `DashboardWidget`.\n   - **Services:** Analytics aggregation, real-time metrics generation, data export.\n   - **APIs:** Endpoints for fetching analytics data, managing widgets, and exporting data.\n   - **Middleware:** Automatic API usage tracking and user activity logging.\n\n2. **Frontend**\n   - **Pages:** Analytics Dashboard.\n   - **Components:** Overview cards, interactive charts, real-time widgets, data export UI.\n   - Efficient connection pooling and background tasks for heavy computations.\n\n#### Data Flow\n1. **Data Collection:** Middleware collects user activity and API usage data.\n2. **Storage:** Data is stored in partitioned PostgreSQL tables.\n3. **Aggregation:** Backend services aggregate data for dashboard views.\n4. **Frontend Fetching:** React Query fetches and caches data for UI components.\n5. **Real-time Updates:** WebSocket streams live metrics to the frontend.\n\n#### Security Considerations\n- **Role-based Access Control:** Different views for superusers and regular users.\n- **Data Anonymization:** Mask sensitive user data in analytics.\n- **Rate Limiting:** Protect APIs from abuse.\n- **Input Validation:** Sanitize all incoming data.\n\n---\n\n### 📋 **Implementation Phases**\n\n#### Phase 1: Core Functionality\n- Implement database models and migrations.\n- Develop backend APIs for analytics data fetching.\n- Create frontend components for dashboard layout and overview cards.\n- Set up middleware for user activity and API usage tracking.\n\n#### Phase 2: Advanced Features\n- Add real-time metrics streaming via WebSocket.\n- Implement interactive charts and filtering options.\n- Develop data export functionality (CSV, JSON, PDF).\n- Introduce role-based access control.\n\n#### Phase 3: Optimization and Polish\n- Optimize database queries with indexing and partitioning.\n- Add Redis caching for frequently accessed data.\n- Conduct performance testing and resolve bottlenecks.\n- Ensure frontend accessibility compliance (ARIA roles, keyboard navigation).\n\n---\n\n### 💻 **Developer Implementation Guide**\n\n#### Backend Implementation\n1. **Database Models**\n   -
